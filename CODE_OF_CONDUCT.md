# Code of Conduct

fmGUI follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and respectful, welcome people of every background and skill level, give and accept helpful
feedback, and focus on what is best for the project and its users. Harassment, insults and personal attacks are not
accepted, in issues, pull requests, reviews or anywhere else in the project.

The full text of the Contributor Covenant 2.1, including how it is enforced, applies to this project.

## Report a problem

If someone breaks this code of conduct, please tell the maintainer,
[@shanto462](https://github.com/shanto462). For a private report, use the
[private report form](https://github.com/shanto462/fmGUI/security/advisories/new) in the Security tab and start the
title with "Code of conduct". Every report is read and kept private.
